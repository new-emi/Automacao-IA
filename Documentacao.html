1. Visão geral

Sistema de envio diário de e-mails personalizados para a lista de clientes da clínica. O conteúdo do dia (mensagem + imagem) é programado por data numa planilha Google; os destinatários vêm da mesma planilha. Roda 100% na nuvem, sem necessidade de computador ligado.

Regra de comportamento: dia sem mensagem cadastrada na planilha = dia sem envio (silencioso, sem erro, sem e-mail vazio).

2. Arquitetura

[cron-job.org] ── todo dia 09:00 (America/New_York, DST automático)
       │  POST na API do GitHub (workflow_dispatch + token PAT)
       ▼
[GitHub Actions] workflow "Email Diario" (ubuntu-latest, Python 3.12)
       │  injeta Secrets e executa enviar.py
       ▼
[enviar.py] ── lê a planilha via service account (gspread)
       │  filtra mensagem do dia + monta HTML personalizado
       ▼
[Gmail SMTP Workspace] smtp.gmail.com:465 (conta da clínica)
       ▼
[Clientes] "How are you going {nome}?" → Hello {nome} - {mensagem} + imagem

3. A planilha

Nome: Automação de EmailsID: <ID_DA_PLANILHA>

O código usa o ID, não o nome. Renomear a planilha é sempre seguro.
AbaConteúdoColunas
Página1DestinatáriosFIRST NAME, EMAIL
Página2Calendário de conteúdoDAY, MESSAGES, IMAGE_URL

Regras de preenchimento

  1. DAY em texto no formato yyyy-MM-dd, uma linha por data.
  2. IMAGE_URL deve ser um link público de imagem (http/https).
  3. Publicar um dia novo = adicionar a linha na Página2. Sem mexer em código ou agendamento.

5. Código

5.1 enviar.py (versão de produção, valores sanitizados)

import os
import smtplib
import time
from datetime import datetime
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from zoneinfo import ZoneInfo

import gspread

# ── Configurações (valores reais via Secrets em produção) ──
SHEET_ID         = "<ID_DA_PLANILHA>"
CREDENTIALS_FILE = os.path.join(os.path.dirname(os.path.abspath(__file__)), "credentials.json")
GMAIL_USER       = os.environ.get("GMAIL_USER", "remetente@dominio.com")
GMAIL_APP_PASS   = os.environ.get("GMAIL_APP_PASS", "xxxx xxxx xxxx xxxx")

# ── 1. Conectar na planilha ───────────────────────────────
gc = gspread.service_account(filename=CREDENTIALS_FILE)
sh = gc.open_by_key(SHEET_ID)

# "Hoje" no fuso da Flórida (Eastern Time), imune a horário de verão
today = datetime.now(ZoneInfo("America/New_York")).date().isoformat()

# ── 2. Mensagem do dia (Página2) ──────────────────────────
messages = sh.worksheet("Página2").get_all_records()
row = next((r for r in messages if str(r.get("DAY", "")).strip() == today), None)

if not row:
    print(f"[{today}] Nenhuma mensagem para hoje. Nada será enviado.")
    raise SystemExit

# ── 3. Destinatários (Página1) ────────────────────────────
recipients = sh.worksheet("Página1").get_all_records()

# ── 4. Enviar ─────────────────────────────────────────────
server = smtplib.SMTP_SSL("smtp.gmail.com", 465)
server.login(GMAIL_USER, GMAIL_APP_PASS)

sent = 0
for r in recipients:
    email = str(r.get("EMAIL", "")).strip()
    nome  = str(r.get("FIRST NAME") or r.get("NOME") or "").strip()
    if not email:
        continue

    html_body = (
        f"<p>Hello {nome} - {row['MESSAGES']}</p>\n"
        f"<img src=\"{row['IMAGE_URL']}\" alt=\"Imagem do dia\" />"
    )

    msg = MIMEMultipart()
    msg["From"] = f"Nome do Remetente <{GMAIL_USER}>"
    msg["To"] = email
    msg["Subject"] = f"How are you going {nome}?"
    msg.attach(MIMEText(html_body, "html"))

    server.sendmail(GMAIL_USER, [email], msg.as_string())
    sent += 1
    print(f"Enviado para {email}")
    time.sleep(1)   # pausa anti-sobrecarga entre envios

server.quit()
print(f"Concluído: {sent} e-mail(s) enviado(s).")

5.2 exemplos/enviar.yml

name: Email Diario

on:
  workflow_dispatch:      # único gatilho: chamado pelo cron-job.org (ou botão manual)

jobs:
  enviar:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Configurar Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Instalar dependencias
        run: pip install gspread

      - name: Criar credentials.json
        env:
          CREDENTIALS_JSON: ${{ secrets.CREDENTIALS_JSON }}
        run: python -c "import os; open('credentials.json', 'w').write(os.environ['CREDENTIALS_JSON'])"

      - name: Enviar e-mails
        env:
          GMAIL_USER: ${{ secrets.GMAIL_USER }}
          GMAIL_APP_PASS: ${{ secrets.GMAIL_APP_PASS }}
        run: python enviar.py

6. Operação no dia a dia

Fluxo das 9h00: cron-job.org dispara → GitHub liga um servidor → Python lê a planilha → filtra o dia → envia um e-mail por destinatário (1s de intervalo) → log registrado.

  • Publicar conteúdo: adicionar linha na Página2.
  • Gerenciar clientes: adicionar/remover linhas na Página1.
  • Pausar um dia: não cadastrar mensagem para aquela data.

Execuções manuais (3 formas)

  1. cron-job.org → botão de teste do job
  2. GitHub → Actions → Email Diario → Run workflow
  3. Local → py enviar.py (usa credenciais de fallback do PC)

Monitoramento

  • GitHub → aba Actions: log completo de cada execução
  • cron-job.org → histórico do job + notificação de falha ativada
  • Log "Nenhuma mensagem para hoje" = comportamento normal, não é erro

9. Segurança (práticas adotadas)

  • Repositório de produção privado; segredos apenas em GitHub Secrets / cron-job.org
  • PAT fine-grained com escopo mínimo (Actions read/write em 1 único repositório)
  • Service account com acesso de leitura apenas à planilha
  • App password em vez da senha real da conta
  • App password pessoal revogada após a migração para a conta da clínica
  • Credenciais locais existem só para teste manual e nunca são commitadas
  • Versão pública (este documento) contém apenas placeholders

11. Reconstruir do zero (resumo)

  1. Criar projeto no Google Cloud + ativar Sheets/Drive API + service account + chave JSON
  2. Compartilhar a planilha com o client_email da service account
  3. Conta Workspace: 2FA + app password
  4. GitHub: repo privado + enviar.py + .github/workflows/enviar.yml
  5. GitHub: Secrets GMAIL_USER, GMAIL_APP_PASS, CREDENTIALS_JSON
  6. GitHub: PAT fine-grained (Actions R/W no repo)
  7. cron-job.org: job POST na API de dispatch, 09:00 America/New_York
  8. Testar (botão de teste) e conferir log + caixa de entrada
